01 / OVERVIEW

What this project
sets out to solve.

A console-based bakery management system using Java objects and collections to handle product selection, stock checks, order finalization, history and sales summaries.

01

The challenge

A bakery needs to connect customer orders, available stock and sales totals. This project models those everyday tasks through focused Java classes.

02

The approach

A console-based bakery management system using Java objects and collections to handle product selection, stock checks, order finalization, history and sales summaries.

Summarize completed orders, revenue and remaining stock.

int stock = inventory.getOrDefault(
  item.getName(), 0
);
if (item.getQuantity() <= stock) {
  inventory.put(item.getName(),
    stock - item.getQuantity());
  items.add(item);
}
